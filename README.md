# 夜访鸡舍 · 捡蛋冲分

[English](README.en.md)

单人像素风网页收集游戏。在每局 **120 秒** 内尽可能多地收集鸡蛋，结束后用钱币升级，再进入更大、更密集的地图。

- **手动拾取**：右键点击地面蛋，或连续右键点击鸡窝，每次立即取一枚；靠近不会自动拾取。WASD／方向键移动，Esc 暂停。网页画布会禁用右键菜单。
- **持续有蛋可捡**：开局铺满鸡蛋，地面不定时分批补充；鸡窝显示 2～6 枚实际库存，取空后补货。鸡蛋飞入角色背包并即时跳分。
- **连续得分**：2.2 秒内继续收集可以维持连捡，每 12 次提高一档倍率，最高四倍；断连不扣已得分数。时间到直接结算，没有固定蛋数和撤离要求。
- **四关地图**：完成一局即解锁下一关。边长按 1、1.2、1.4、1.6 倍增加；障碍、鸡窝和散落物逐渐增多。镜头等比拉远，鸡蛋保留可点击尺寸。
- **黄金鸡**：第 3、4 关过半时出现，留下基础五分的金蛋；第 4 关后段再加入一只。普通蛋基础一分。
- **跨局升级**：每五分兑换一枚钱币，购买连收范围、额外收获、鸡窝补货升级，各五级。分数与钱币分开，花钱不扣最高分。进度保存在当前浏览器；换设备／浏览器不会自动同步。

## 运行与验证

Godot **4.5.1 Standard**，Compatibility 渲染器，960×540 设计尺寸。导入 `project.godot` 后按 F5。主场景为 `scenes/arcade/game.tscn`，旧潜行入口 `game.tscn` 保留供参考。

```bash
godot --headless --path . --import
godot --headless --path . --fixed-fps 60 --script tests/arcade_flow.gd
godot --headless --path . --export-release Web build/web/index.html
```

导出需安装匹配的 4.5.1 模板；云环境可使用 `.codex/setup.sh`。构建产物不提交 Git。Web 版需通过 HTTP(S) 提供。
